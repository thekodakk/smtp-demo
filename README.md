# SMTP contact form demo

Flask SMTP iletişim formu örneği. `Untitled-1.html` ön yüzü içerir.

Python ortamında `pip install -r requirements.txt` çalıştırın. `.env.example`
dosyasındaki değişkenleri kendi SMTP bilgilerinizle süreç ortamına tanımlayın;
bu uygulama `.env` dosyasını otomatik yüklemez. Ardından `python app.py`
ile yerel geliştirme sunucusunu başlatın. HTML dosyasını tarayıcıda açın.
